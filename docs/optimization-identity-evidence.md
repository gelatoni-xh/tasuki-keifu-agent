# 身份判断证据与合并输出优化

第 102 回箱根预选会复核发现：已有同名、同读音、同校与学年连续的证据时，研究仍可能把生日或注册号当成必备条件；另有模型表达了合并结论，但单项 `merge` 缺少保留目标，无法形成合并计划。

轻型和重型判断现在明确可综合采用独立赛事证据和相容时间线，不强制生日或注册号；不同生日、明确时间矛盾和有竞争力的候选仍需排查，证据不足时继续待确认。较晚赛事可作为模型的线索，但没有扩大确定性规则的自动匹配范围：同校同名、缺失年级以及不同届同名都不能单独证明同人。

人物单项 `match` 必须指定候选目标；`merge` 必须指定保留目标和至少一个不同且不重复的待合并候选，全部属于允许范围。无效回答沿现有机制最多尝试三次，仍不合格则停止并留下诊断，不从文字中猜 ID。合并前检查全部档案之间的同赛事成绩碰撞；原有证据校验、落库碰撞检查、履历去重和事务约束保留。

此改动不重跑历史赛事，也不保证具体历史案例必然自动解决。模型判断仍可能出错；实际 resolved 比例、错误合并和耗时需在后续新赛事中观察。涉及数据回填时仍应核对业务结果。
